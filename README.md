## About

**TaraTari Tools** is a lightweight, single-file web directory that helps you discover hand-picked **open-source, privacy-respecting software** across every major platform — Windows, Linux, macOS, Android, iOS, and the web.

It also ships with a **Windows Optimization Hub** (featuring the TaraTari OS Tool powered by Atlas OS and ReviOS playbooks), quick PowerShell debloat commands, package manager guides, and a curated **Windows ISO collection** with both official Microsoft links and community mirrors.

Built as a **single `index.html`** file — no build step, no dependencies, no tracking.

---

## Features

### Curated Software Directory
- **50+ hand-picked tools** across 19 categories: Browsers, Archive, Media, Password Managers, Screenshots, Gaming, Package Managers, Operating Systems, and more.
- Platform filter chips: **All / Mobile / PC**.
- Instant fuzzy search across name, category, and description.
- Trending carousel highlighting the most useful picks.
- OS badges on every tool (Windows, Linux, macOS, Android, iOS, Web).

### Windows Optimization Hub
- **TaraTari OS Tool** — a guided 3-step stepper to apply **Atlas OS** or **ReviOS** playbooks to Windows 10 / 11.
- State saved in `localStorage` so your selection persists across sessions.
- Quick **PowerShell one-liner tweaks** (Chris Titus Utility, Just The Browser) with one-click copy buttons.
- Step-by-step **WinGet installation guide** for setting up the Windows Package Manager.
- Bulk-install recommendations (Winstall, Ninite, UniGetUI).

### Windows ISOs Page
- **Windows 11 25H2** (Official ISO, Build 26200.6584)
- **Windows 11 LTSC** (Official ISO, Build 26100.1742)
- **Windows 10** (Consumer editions)
- **Windows 10 LTSC**
- **Windows 7 SP1**
- Clear **Official ISO** vs **Community Mirror** badges.

### Design & UX
- Material 3-inspired dark theme with a green/mint accent palette.
- Fully responsive — desktop nav tabs plus a mobile bottom navigation bar.
- Smooth page transitions, back-to-top button, and a floating GitHub button.
- Zero build step, zero dependencies — pure HTML, CSS, and vanilla JS.

## Suggest a Tool

Want to see a new app, optimizer, or ISO added to TaraTari Tools? Submit it through the form below. Every suggestion is reviewed before it goes live.

**[Submit a tool suggestion](https://tally.so/r/YOUR_FORM_ID)**

### Guidelines
- Only suggest **open-source** or **privacy-respecting** tools.
- Link the **official download page** (not third-party mirrors).
- Keep descriptions to one sentence — neutral and factual.
- No trackers, ads, affiliate links, or closed-source bloatware.

### Report a Bug
Spotted something broken? Use the same form and pick **Bug report** — include what you expected, what actually happened, and your browser and OS if it is a UI issue.

## Disclaimer

- **TaraTari Tools is not affiliated with Microsoft, Atlas OS, ReviOS, or any listed project.**
- Windows ISOs are **provided as-is**. Official ISOs are hosted by Microsoft; community mirrors are third-party. **Always verify SHA-256 hashes** before installing.
