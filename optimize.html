Step 2 — Before you run the playbook

Two things to know before applying an optimization playbook.

shield

Windows Defender warning

Playbooks can disable Windows Defender to squeeze out more performance. If you're new to Windows and don't know how to spot bad links or malware, do NOT disable Defender. Leave it on during playbook installation.

Advanced users can disable Defender and use Malwarebytes instead. Scan occasionally. Always browse safely.

Skip Edge and Chrome

Chrome eats RAM and uses 8GB+ of storage for its bundled Gemini models. Edge is not much better. Switch to Firefox or Brave.

If those feel heavy, try Helium (Chromium-based) or Waterfox (Firefox-based). For maximum privacy: LibreWolf.

Step 2 — Activate Shizuku

Shizuku needs to be started once. Pick whichever method is easier — USB or wireless debugging. After it's running, you can close the terminal.

usb Method A — ADB over USB

Enable USB debugging in Developer Options, connect to a PC, then run:

terminal Start Shizuku · v11.2.0+
ADB Shell
$> adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh

wifi Method B — Wireless debugging (Android 11+)

Open Shizuku → "Start via Wireless debugging" → pair using the pairing code from Developer Options. No PC required.

info Shizuku resets on every reboot. Just open the app and re-run the steps — it takes 10 seconds once it's set up.

Step 3 — Debloat with Canta

Open Canta. It connects to Shizuku, lists every system package on your phone, and lets you uninstall them one by one. Take your time — this is the important part.

warning

Be careful what you uninstall

Removing the wrong package can break core phone functions (camera, calls, fingerprint sensor). Stick to obvious bloat — preinstalled social apps, trial software, duplicated manufacturer stores.

Don't know where to start? Search YouTube for "how to debloat Android using Canta" — there are step-by-step videos for every major phone brand.
