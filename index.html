How to install WinGet (Windows Package Manager)

1. Check if you already have it: Open PowerShell and type winget --version — if you see a version number, you're good to go.

2. If not installed, run this in PowerShell (Admin):

PowerShell (Admin)
PS> $progressPreference = 'silentlyContinue'; $url = $(Invoke-RestMethod https://api.github.com/repos/microsoft/winget-cli/releases/latest).assets.browser_download_url | Where-Object {$_.EndsWith(".msixbundle")}; $file = "$env:TEMP\Microsoft.DesktopAppInstaller.msixbundle"; Invoke-WebRequest -Uri $url -OutFile $file; Add-AppxPackage $file

This downloads the latest WinGet installer from GitHub and installs it. Close and reopen PowerShell, then run winget --version to confirm.
